# Report 화면 구현

## 1. 구현 요구사항

1. 신고하기 화면은 설계된 디자인이 없으므로, Design Pipeline 스킬을 이용하여 앱 테마에 적합한 디자인을 설계/구현/적용한다.
    - Design Pipeline 스킬을 통해 디자인에 대하여 섬세한 검증을 진행하며, AI Slop에서 벗어남과 동시에 앱 테마와 어우러지는 디자인이어야한다.
2. '신고'라는 컨텐츠의 구성은 다음과 같다.
    - 제목
    - 본문
    - 사진(최대 10장까지 첨부 가능)
3. 예상하는 사용자 동작 흐름은 다음과 같다.
    - 사용자가 부적절한 게시글 발견
    - 게시글 상세 화면 우측 상단의 점 세 개 버튼을 눌러 드롭다운 메뉴 표시,'신고하기' 탭으로 이동
    - 신고 내용 작성 후 제출
    - 사용자가 제출한 신고 내용은 운영진 이메일로 전달됨
4. 신고 기능이 실제로 작동할 경우 이메일로 내용을 전달받을 예정이나, 현 단계에서는 이메일로 전달하는 부분까지는 구현하지 않는다.
    - 제출 버튼을 누를 경우 잠깐의 대기 애니메이션을 통해 신고 내용이 실제로 제출되고 있는 듯한 경험을 주어야한다.
    - 추후 이메일로 전송 기능을 연동할 예정이다.
