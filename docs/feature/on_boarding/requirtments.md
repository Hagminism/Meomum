## 2. 구현 요구사항

- 이번 구현은 '온보딩 화면 UI 구현 + 인증 상태에 따른 리다이렉션 처리 + supabase 연동 + 커뮤니티 첫 진입 시 본인 거주 지역 게시판 표시'까지를 최초 범위로
  한다.
- 온보딩 화면 경로는 다음과 같이 정한다.
    - 첫 방문 환영 페이지: /on-boarding(이미 정의되어있음)
    - 프로필 생성 페이지: /on-boarding/create-profile
    - 거주 지역 선택 페이지: /on-boarding/create-profile/select-region
    - 프로필 생성 페이지와 거주 지역 선택 페이지는 첫 방문 환영 페이지 하위 중첩 라우트로 설계한다.
- 온보딩 화면은 회원가입 후 최초 로그인 시에 표시되어야한다.
    - 최초 로그인 후 온보딩 화면을 본 상태에서 지역 선택을 하지 않고 앱을 종료했을 경우, 다시 앱을 켰을 때 온보딩 화면이 표시되어야한다.
    - 세션이 끊어졌을 경우 다시 로그인 화면으로 돌아가야한다.
- 온보딩 화면 순서 구성은 다음과 같다: '1. 첫 방문 환영 페이지 -> 2. 프로필 생성 -> 3. 거주 지역 선택'
    - 첫 방문 환영 페이지는 아래 링크의 피그마 컴포넌트의 디자인을 따른다.
        - https://www.figma.com/design/7a81lvN3BOxOTBtC65JBap/2026-%EA%B4%80%EA%B4%91%EB%8D%B0%EC%9D%B4%ED%84%B0-%ED%99%9C%EC%9A%A9-%EA%B3%B5%EB%AA%A8%EC%A0%84?node-id=88-1443&t=3NOWn549OlsxuGmN-4
        - 하단 버튼 타이틀이 '지역 선택하기'로 되어있는데, '프로필 만들기'로 바꿔서 적용한다.
    - 프로필 생성 페이지는 아래 링크의 피그마 컴포넌트의 디자인을 따른다.
        - https://www.figma.com/design/7a81lvN3BOxOTBtC65JBap/2026-%EA%B4%80%EA%B4%91%EB%8D%B0%EC%9D%B4%ED%84%B0-%ED%99%9C%EC%9A%A9-%EA%B3%B5%EB%AA%A8%EC%A0%84?node-id=607-1446&t=3NOWn549OlsxuGmN-4
        - 사용자가 회원가입 할 때 선택한 소셜 로그인 플랫폼의 프로필 사진/닉네임을 기본값으로 표시해야한다.
        - 원형의 프로필 사진 표시부를 누르면 사진 보관함을 열어서 프로필 사진을 수정할 수 있어야한다.
        - 닉네임은 중복을 허용한다.
    - 거주 지역 선택 UI은 현재 디자인 된 것이 없으므로 앞선 두 화면과 조화로운 수준에서 임의로 디자인을 적용한다.
        - 디자인 설계 및 구현 시에는 Codex의 taste skill을 사용하여 AI-Slop을 줄이는 방향으로 진행해야한다.
        - 지역 선택을 진행할 때는 기존에 존재하는 바텀시트 위젯을 재사용한다.
            - [community_region_bottom_sheet.dart](/Users/ihagmin/Meomum/lib/feature/community/presentation/component/region/community_region_bottom_sheet.dart)
- supabase 연동은 아래와 같이 진행한다.
    - 온보딩 플로우가 없는 현재는 회원가입 진행 시 'auth0 인증 -> accounts 테이블에 각 소셜 플랫폼 별 auth0 계정 정보 저장 -> profiles
      테이블에 닉네임/프로필 사진 저장' 순서로 진행된다.
    - 온보딩 플로우가 추가될 경우 거주 지역에 대한 컬럼이 profiles 테이블에 추가되어야한다.
        - 회원가입 후 온보딩 화면 진입 시점까지는 거주 지역 컬럼이 null로 저장되어야한다.
        - 사용자가 거주 지역을 선택하면 해당 값을 컬럼에 저장 후 홈 화면으로 이동해야한다.
        - 앱 실행 시 사용자의 거주 지역 컬럼이 null일 경우, 사용자가 거주 지역 선택을 하지 않은 것으로 판단한다.
    - 최종적으로는 회원가입 진행 시 'auth0 인증 -> accounts 테이블에 각 소셜 플랫폼 별 auth0 계정 정보 저장 -> profiles
      테이블에 닉네임/프로필 사진 저장(거주 지역은 null) -> 사용자가 온보딩에서 거주 지역 선택 시 profiles 테이블에 선택된 거주 지역 값을 저장' 순서로
      동작해야한다.
    - 연동은 supabase mcp를 통해 진행한다.
- 온보딩 리다이렉션 조건은 거주 지역 선택 여부를 통해 판단한다.
    - profiles 테이블의 거주 지역 컬림이 null일 경우, 사용자가 거주 지역 선택을 하지 않은 것으로 판단한다.
    - 이 경우 항상 첫 방문 환영 페이지로 리다이렉트 해야한다.
- 온보딩에서 지역 선택을 완료한 후 정상적으로 홈 화면으로 넘어온 경우, 앱 실행 후 커뮤니티 탭 최초 진입 시에는 본인 거주 지역의 게시판을 표시해야한다.
