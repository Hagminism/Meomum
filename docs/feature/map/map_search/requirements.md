# 지도 검색(MapSearch) 기능 구현

## 구현 요구사항

### 1. 지도 화면 하단 drawer

- 동네지도 탭에 진입 시 최초 반경 검색 or 이 위치에서 재검색을 통해 탐색한 매장들을 지도 화면 하단 drawer에 세로 목록으로 표시해야한다.
- 사용자 위치로부터 가까운 매장이 상단에 표시되도록 기본 정렬하며, 필요한 경우 추후 새로운 기준을 통한 정렬 기능을 추가한다.
    - 필터칩 아래에 가까운 매장이 먼저 표시된다는 문구를 작게 표시한다.
- 필터칩을 누를 경우 해당 카테고리에 해당하는 매장들만 표시되어야한다.

### 2. 지도 화면 상단 검색 바를 통한 장소 검색

- 사용자가 지도 화면 상단 검색 바를 탭할 시 장소 검색 화면으로 이동해야한다.
- 디렉터리 구성은 다음과 같이 정한다.
    - 루트의 feature 디렉터리 하위에 별도의 feature 1개를 추가로 구성한다.
    - 지도: /feature/map(이미 정의되어있음)
    - 장소 검색: /feature/map_search
- 지도 하위 화면 경로는 다음과 같이 정한다.
    - 지도: /map(이미 정의되어있음)
    - 장소 검색: /map/map-search
    - 장소 검색 페이지는 지도 하위 중첩 라우트로 설계한다.
- 장소 검색 페이지는 설계된 디자인이 없으므로, Design Pipeline 스킬을 이용하여 앱 테마에 적합한 디자인을 설계/구현/적용한다.
    - Design Pipeline 스킬을 통해 디자인에 대하여 섬세한 검증을 진행하며, AI Slop에서 벗어남과 동시에 앱 테마와 어우러지는 디자인이어야한다.
    - 상단에는 검색 바가 위치하고, 키워드를 입력하여 검색을 시도할 시 검색바 하단에 세로 목록으로 매장들의 정보를 표시한다.
- 장소 검색에서 검색 시에는 사용자 반경 주변 매장들에 대해서만 검색을 시도하는 게 아니라, 모든 매장에 대해 검색을 시도한다.
    - 검색 속도 저하 등 성능 문제 발생의 여지가 있을 경우 개발자와 상의하여 다른 방식을 채택한다.
    - 검색 결과가 없을 경우 결과가 없다는 정보를 사용자에게 알려주어야한다.
    - 사용자가 키워드를 입력할 때 검색바 하단에 표시되는 매장 정보 목록을 표시하는 로직에는 쓰로틀을 적용해야한다.
        - 자모 하나하나를 입력할 때마다 목록을 갱신하는 게 아니라, 사용자가 입력을 멈춘 시점으로부터 일정 시간 이후에 목록을 갱신해야한다.
