# Post_detail 화면 구현
## 1. 연결 채널 
9wx9vwo6
## 2. 구현 요구사항
1. /home에서 게시글을 누를 때와 /community에서 게시글을 누를 때 모두 db에 저장되어있는 게시글을 조회하므로 같은 UI를 적용할 것.
    - but, 하나의 파일을 두 경로에 적용하는 것이 아니라, 각 feature 디렉터리에 같은 UI를 가진 파일을 하나씩 만들어서 적용할 것.
    - ex) /home_post_detail 경로에는 home_post_detail_screen.dart 파일을, /community_post_detail 경로에는 community_post_detail_screen.dart 파일을 기반으로 구성해야함.
2. /home과 /community 경로에서 모두 중첩 라우트로 구성해야함.
3. 댓글 기능의 경우 현재 도메인 모델, db 테이블, 저장 및 조회 로직 등 아무 것도 구현되어있지 않으므로, 피그마처럼 mock 데이터로 표시만 해놓을 것.
4. 댓글 입력창의 경우 아무 내용도 적혀있지 않을 때는 입력창만 존재하다가, 사용자가 무언가 작성하기 시작하면 입력창 우측에 댓글 달기 버튼이 표시되어야함.
    - 이때, 버튼 생성은 애니메이션으로 자연스럽게 처리할 것.
5. 사진의 경우 하나만 선택 할 수 있게 할 예정. 사진 보관함에서 사진을 선택하면 사진 선택 버튼에 작게 썸네일 이미지가 보여야함.
6. 우측 상단의 점 세개 버튼을 누르면 글 수정, 글 삭제, 신고하기를 드롭다운으로 표시한다.
    - 글 수정/글 삭제 기능은 본인이 작성한 글을 조회할 때만 표시한다.
    - 신고하기의 경우 모든 글에 대해 노출한다.
