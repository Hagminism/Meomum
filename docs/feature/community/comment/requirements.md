# 댓글(Comment) 기능 구현

## 구현 요구사항

- 사용자는 게시글 상세 화면에서 댓글을 작성할 수 있어야 한다.
- 하단의 댓글 입력창에 내용을 입력하고 사진(선택)을 선택한 후 작성 버튼을 누르면 해당 게시글에 댓글이 추가되어야 한다.
- 프로필과 댓글 내용을 담을 위젯 디자인은 현재 구현되어있는 위젯을 기반으로 한다.
    - 댓글을 작성한 사용자의 프로필 사진, 닉네임, 거주 지역, 작성한 시점으로부터 얼마나 지났는지 등의 정보가 표시되어야 한다.
    - 게시글 작성자가 댓글을 남겼을 경우 현재 구현되어있는 것처럼 작성자라고 뱃지를 달아 명시해야한다.
    - 관계자 인증 뱃지는 현재 기능이 구현되어있지 않으므로 추후 구현될 때를 대비하여 여지만 남겨놓는다.
- 댓글 우측에 있는 점 세 개 버튼을 누르면 드롭다운 버튼을 표시하며, 댓글 수정/삭제/신고하기 기능을 포함해야한다.
    - 수정을 선택할 시 하단 입력창과 별도로 댓글 텍스트에 입력창이 표시되며, 댓글을 빠르게 수정할 수 있어야 한다.
    - 삭제를 선택할 시 사용자 확인을 요하는 다이얼로그를 표시하며, 확인할 경우 삭제한다.
        - 댓글을 삭제할 경우 댓글 위젯이 통째로 제거되는 것이 아니라, 내용이 "삭제되었습니다" 등의 문구로 변경되어야한다.
    - 신고하기는 게시글 신고하기 UI 템플릿을 가져다 사용한다.
- 댓글 본문 하단 좋아요 버튼을 통해 댓글 좋아요 기능을 제공해야한다.
- 댓글 본문 하단 대댓글 버튼을 통해 대댓글 기능을 제공해야한다.
    - 대댓글 버튼을 누를 경우 해당 댓글 위젯 배경색이 연한 초록 계열 색으로 변하면서, 해당 댓글에 대한 대댓글을 작성 중이라는 것을 사용자가 쉽게 알 수 있게 해야한다.
    - 대댓글 작성은 기존의 댓글 작성창을 재사용한다.(UI를 재사용한다는 말이 아니라, 이미 구현되어있는 화면 최하단 댓글 작성창을 함께 쓴다는 말이다.)
    - 대댓글의 경우 본 댓글보다 한 단 들여쓰기된 상태로 표시되어야한다. 단, 대댓글의 대댓글은 최초 같은 단 수준을 유지한다.
        - ex) 본 댓글의 들여쓰기 수준을 0, 최초 대댓글의 들여쓰기 수준을 1이라고 한다면, 대댓글의 대댓글들은 1 수준을 유지한다.
- 마이페이지 상세 페이지에 존재하는 "내가 쓴 댓글" 탭에서 사용자가 작성한 댓글을 조회할 수 있어야 한다.
    - 댓글은 "내가 쓴 글" 탭처럼 세로 목록으로 표시해야한다.
    - 댓글을 누를 경우 댓글을 단 게시글로 이동하며, 해당 댓글 위치로 스크롤을 자동 이동시켜 표시해야한다.
