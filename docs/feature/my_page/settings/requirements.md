# Settings 화면 구현

## 구현 요구사항

- 디렉터리 구성은 다음과 같이 정한다.
    - 루트의 feature 디렉터리 하위에 별도의 feature 1개를 추가로 구성한다.
    - 마이페이지: /feature/my_page(이미 정의되어있음)
    - 설정: /feature/settings
- 마이페이지 하위 화면 경로는 다음과 같이 정한다.
    - 마이페이지: /my-page(이미 정의되어있음)
    - 설정: /my-page/settings
    - 설정 페이지는 마이페이지 하위 중첩 라우트로 설계한다.
- 설정 페이지는 설계된 디자인이 없으므로, Design Pipeline 스킬을 이용하여 앱 테마에 적합한 디자인을 설계/구현/적용한다.
    - Design Pipeline 스킬을 통해 디자인에 대하여 섬세한 검증을 진행하며, AI Slop에서 벗어남과 동시에 앱 테마와 어우러지는 디자인이어야한다.
- 마이페이지 화면 우측 상단에 위치한 톱니바퀴 버튼를 눌렀을 때 설정 페이지로 이동해야한다.
- 상세 페이지 상단 앱바는 기존에 정의한 위젯을 재사용한다.
    - [custom_app_bar.dart](/Users/ihagmin/Meomum/lib/core/presentation/component/custom_app_bar.dart)
    - optional 파라미터의 추가가 필요한 경우 nullable로 선언하여 사용한다.
- 설정 페이지 컨텐츠의 구성은 다음과 같다.
    - 공지사항
        - 공지사항의 경우 mock 데이터로 구성하며, 그 중 하나는 서비스 런칭 축하 글을 내용으로 한다.
        - 개수는 3개로 정한다.
    - 약관 및 정책
        - 해당 버튼을 누르면 외부 링크로 이동한다.
        - 개인정보처리방침: https://app.notion.com/p/3baf5b5d5eb48051adccda213145fbdf?source=copy_link
    - 로그아웃
        - 로그아웃 버튼을 누르면 확인 다이얼로그를 표시한 뒤, 사용자가 확인 버튼을 누르면 로그아웃한다.
    - 회원 탈퇴
        - 회원 탈퇴 버튼 아래에는 경고 문구를 표시해야하며, 탈퇴 버튼을 누르면 확인 다이얼로그를 표시한 뒤, 사용자가 확인 버튼을 누르면 탈퇴한다.
